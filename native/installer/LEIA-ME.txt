ÍNDIGO PARA PC - versão @VERSAO@
Consoles: SNES (Super Famicom), NES (Famicom), Game Boy, Game Boy Color, Game Boy Advance, Master System, Game Gear,
Neo Geo Pocket e Neo Geo Pocket Color

Como usar
- Abra indigo.exe e arraste um jogo (.sfc, .smc, .nes, .gb, .gbc, .gba, .sms, .gg, .ngp, .ngc ou .zip) para a janela, ou aperte Ctrl+O.
- A tela inicial mostra "Continuar <jogo>" (volta exatamente de onde você parou) e os últimos jogos abertos.

Instalar
- Indigo-@VERSAO@-instalador.exe: instala só para você (não pede administrador), cria o atalho no menu Iniciar
  e, se quiser, faz os jogos abrirem com dois cliques. Para desinstalar: Configurações > Aplicativos > Índigo.
  Os saves NÃO são apagados ao desinstalar nem ao instalar uma versão nova por cima.
- Ou a versão portátil (o .zip): é só descompactar e abrir indigo.exe.

Índigo 1.0

Novo na 0.9
- Estante: tela inicial > "Estante: todos os jogos". Mostra todos os jogos (favoritos primeiro), em páginas de
  8, com filtro por console. Ao lado aparece a capa: a tela do jogo na última vez que você fechou
  (no menu do jogo, "Usar esta tela como capa" troca a capa; "Favorito" marca o jogo).
- Pastas de jogos: tela inicial > "Pastas de jogos" > "Adicionar pasta". Todos os jogos da pasta (e das

  Select + Start abre o menu.
- "Sobre e novidades" na tela inicial: versão, o que mudou em cada versão e, no PC, a opção

Novo na 0.6
- Nuvem dos saves (a mesma do site, com o mesmo PIN): menu "Nuvem dos saves" > "Digitar o PIN".
  Depois disso o Índigo sincroniza sozinho: ao abrir, traz o save mais novo de outro aparelho; ao jogar, envia
  o seu. Se os dois lados mudaram, fica o mais novo e o outro vai para "Versões anteriores do save".
- Backup .indigo (o mesmo formato do site): tela inicial > "Backup (.indigo)" para exportar (com ou sem as
  ROMs). Para importar, é só abrir o arquivo .indigo no Índigo. Os estados salvos do site não vêm junto
  (o formato é outro); jogos, saves e versões anteriores vêm.

Novo na 0.5
- Esc (ou o botão Guia do controle, ou Start + Select juntos) abre o menu: salvar e carregar estado nos 9 espaços
  com data e miniatura, acelerar 4x, reiniciar, paleta, versões anteriores do save, abrir ou fechar jogo.
- Ao fechar o jogo ou o Índigo, o ponto em que você estava fica guardado ("Continuar").
- Jogos dentro de .zip abrem direto.
- Cada save guarda até 12 versões anteriores (uma a cada 10 minutos de jogo, no máximo). Se um save der
  problema, volte para uma versão anterior pelo menu; o save atual também fica guardado.
- Se o Windows mostrar "O Windows protegeu o computador", clique em "Mais informações" e
  "Executar assim mesmo" (o programa não tem assinatura digital).

Teclado (igual à versão web)
- Setas: direcional
- X: A (botão 2 no Master System/Game Gear)
- Z: B (botão 1 no Master System/Game Gear)
- A / S: L / R (Game Boy Advance)
- Enter: Start (Pause no Master System, Option no Neo Geo Pocket)
- Backspace: Select (Option no Neo Geo Pocket)
- Espaço (segurar): acelerar 4x
- F5: salvar estado       F8: carregar estado       1 a 9: escolher o espaço
- P: pausar   Ctrl+R: reiniciar   F3: trocar paleta do Game Boy   F11 ou Alt+Enter: tela cheia

Controle (Xbox, GameSir e outros): A = A, B ou X = B, LB/RB = L/R, Menu = Start, View = Select, RT = acelerar,
clique do analógico esquerdo = pausar.

Saves e estados ficam em %APPDATA%\Indigo\Indigo\ (com o nome completo do jogo, ex.: Pokemon Emerald.gba.sav)
Na primeira vez que um jogo é aberto, um .sav (ou .ngf, no Neo Geo Pocket) com o mesmo nome,
ao lado da ROM, é importado. Saves de GBA da versão web (com o ajuste do relógio) também funcionam.

Game Boy Advance
- Usa a BIOS própria do Índigo: o jogo começa direto, sem a animação da Nintendo.
- Se você tiver a BIOS do seu próprio GBA (arquivo de 16 KB, por exemplo gba_bios.bin), abra esse arquivo
  no Índigo uma vez: ele é copiado para a pasta de dados e passa a ser usado nos jogos de GBA.
  Para voltar à BIOS própria, apague %APPDATA%\Indigo\Indigo\gba_bios.bin.
- O relógio dos cartuchos (Pokémon Ruby/Sapphire/Emerald, Boktai) segue a hora do Windows.

O Neo Geo Pocket usa a BIOS própria do Índigo: o jogo começa direto, sem o menu da SNK.
